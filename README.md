# ComReport-v1.0
ComReport, bilgisayarın donanım ve sistem bilgilerini tek bir yerde görüntüleyen ve bu bilgileri PDF raporu olarak kaydetmeyi sağlayan Python tabanlı bir sistem analiz aracıdır. CPU, RAM, disk, GPU, işletim sistemi ve Wi-Fi gibi bilgileri otomatik olarak toplar ve kullanıcıya anlaşılır bir şekilde sunar.
